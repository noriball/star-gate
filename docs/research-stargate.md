# Star Gate シーン調査メモ (2001年宇宙の旅, 1968)

調査日: 2026-10-15 / 状態: 第1次調査(Web二次資料ベース)。[確認済] = 複数/明示ソースあり、[要検証] = 記憶・単一ソース・未確認。

## 1. 概要
- 監督 Stanley Kubrick、特殊撮影監督 Douglas Trumbull(当時20代)。映画終盤、ボーマンがモノリス経由で木星圏を通過するシーケンス。
- 中核技術は **スリットスキャン(slit-scan)**。長時間露光中にカメラまたは原画を動かし、スリット越しに撮ることで光の筋(ストリーク)を作る。[確認済]
- 系譜: 19世紀の写真(スリット付きマスクを動かす)/ 競馬のフォトフィニッシュ(スリット固定でフィルムが動く = 横軸が時間)→ John Whitney(『めまい』タイトル)→ Trumbull(Graphic Films で Whitney, Con Pederson と実験)。Whitney が Kubrick にテストフィルムを送った。[確認済]
- Trumbull の着想: 「スリットをカメラの外に出し、2次元ではなく3次元空間で動かす」。[確認済]
- 先行する抽象映像: Jordan Belson, Whitney の作品が Star Gate の着想源とされる。[確認済(示唆)]

## 2. 装置の仕組み(Star Gate 用スリットスキャン機)
| 要素 | 内容 | 確度 |
|---|---|---|
| 規模 | 約 30ft x 30ft の大型機械 | 確認済 |
| カメラ | ウォームギア駆動のドリーに載り、1コマ露光の間、スリット側へゆっくり前進/後退。シャッターは開きっぱなし | 確認済 |
| マスク | 大きな黒いマスクに高さ約4ftのスリット(別報告: 高さ6ftの回転可能な金属板、12ft幅の背面ガラスパネルの前) | 要検証(ソース間で相違) |
| 原画 | 背面ライトの当たった抽象画、花やサンゴの拡大写真。カメラ進行方向と直交する台車で左右にスライド | 確認済 |
| 露光 | 1コマ約4〜5分。24時間稼働で数か月。撮影分の約1/4のみ使用 | 確認済(4分 vs 5分の差あり) |
| 二重露光 | カメラ位置を変えて2回露光し、反対側に第2の壁を作ってトンネル状にする | 確認済(1ソース) |
| 自動化 | 一度動き出せば全自動。原画の破片が外れて飛ぶのを監視 | 確認済 |
| 色 | 原画の色/後段の光学処理で色変化。詳細未確認 | 要検証 |

幾何的な理解(アプリ化の核):
- スリット越しに見える原画の「線」を、カメラ移動で奥行き方向に引き伸ばす。カメラが近いほどスリット像の拡大率が大きい → 画面中心へ向かう(または中心から出る)放射状の流れ = 無限トンネル感。
- 各コマで原画の開始位置を少しずつずらす → 時間方向のアニメーション。
- 1コマ = 「スリット位置 × カメラ位置 × 原画位置」の長時間積分。デジタルなら、露光中のカメラ位置を多数サンプリングし加算合成すればよい。

## 3. シーケンス内の他の要素
- **Mindbender**: 上半分に配置された7つの八面体(各4面見え、各面3パス)+スリットスキャン(縦・横)+アクリル板の発光による脈動。全85パスを同一フィルムに多重露光。[確認済(1ソース)]
- **Jupiter machine**: スリットスキャンを応用し木星像を作る機械。[確認済(1ソース)]
- **風景ショット**(色反転・フィルタ・光学処理した空撮の山/峡谷、化学・インク系の抽象): [要検証 — 今回の資料では未確認。次回調査対象]
- Kubrick の要求水準が高く、多数のリテイクあり。[確認済]

### 寸法・露光(解決度: 部分的)
| 項目 | 報告値 | 出典/確度 |
|---|---|---|
| スリット板 | 高さ6ft(約1.8m)の回転可能な金属板、細いスリット | 複数ソース一致。確認済 |
| 背面パネル | 幅12ft(約3.7m)の背面照明ガラス(透過原画+セルゲル) | 同上。確認済 |
| カメラ軌道 | 14ft(約4.3m)のトラックをスリットへ前進。ブレーキでガラス衝突防止、小モーターで徐々に加速 | 単一ソース(fellinis, Cinefex#85/Agel引用)。要検証 |
| 1コマ露光 | 2回露光(各約45〜60秒)=合計約1〜2分/コマ。別発言で「1コマ約1分」「4分」「5分」 | 発言が不一致。論文本文で要確認 |
| 撮影フォーマット | 65mmカメラ(Mitchell)。レビュー用は35mmアナモ焼き | 確認済 |
| 絞り/被写界深度 | F/1.8、被写界深度約15ft〜1.5inch | 単一ソース(1968 AC引用)。要検証 |
| 継続時間 | 星門回廊だけで連続撮影9か月以上、1テイク最長36時間 | 確認済(Trumbull談) |
| 機械の大きさ | 「部屋の3倍」(Trumbull) / 約30x30ft(別) | 確認済 |
- 2回露光: スリット位置を左右(交互)にオフセットし、2枚の「無限平面(壁)」を作る。[確認済 — 複数ソース]
- スリットは中心からオフセット。ドリーはカメラ/被写体を露光中に動かす。[確認済(1ソース)]
- 原画は科学写真・建築図面・回路基板・電子顕微鏡写真・結晶構造・絵具や化学薬品のスローモ撮影。[確認済(2次資料)]

### 色処理(解決度: 部分的)
- 風景は光学プリンタで**3色分解(Technicolor三色式の混合)をランダムに混ぜた**。YCM分解でのカメラ内コンタクトプリント。[確認済(Trumbull談+2次)]
- ラボ担当 Bryan Loftus の説明: 3色ストリップから高コントラスト3種+低コントラスト3種(計6)を作り、ショット当たり**計12ストリップ**。絞り・カラーフィルタ設定をランダムにする**3つの回転ホイール**を自作。[単一ソース。要検証 — 「12」の内訳が3+3=6と合わないので原典で確認]
- ほぼ全ショットがグレースケール/カラーチャート付きで開始(色タイミング用)。[確認済]
- ソラリゼーション/ネガ反転と説明する資料もあるが、Loftus説と別物。[不確実]

### 風景ショット(解決度: 大筋は判明)
- 空撮素材: Kubrickの指示でセカンドユニット(Robert Gaffney)がヘリで低空撮影。ロケ地は**スコットランド(ヘブリディーズ諸島)**と**アメリカ・モニュメントバレー(アリゾナ/ユタ)**。[確認済(複数)]
- Trumbull自身は風景を撮っておらず、光学処理(色分解・フィルタ・ネガ/ポジ)が彼ら+ラボの仕事。[確認済]
- 宇宙爆発(星雲)のカット: 黒インクとバナナオイルに絵具を滴下、オーバークランク+逆転で撮影。[確認済(2次)]

### Mindbender(解決度: 部分的)
- 「35mm映写プレートを菱形(ダイヤモンド)の立体に投影し、パスを何度も重ねた」。各面が映画として投影される。[Trumbull談で確認]
- 前回の「7八面体・各4面x3パス=85パス」は1ソースのみ、今回Trumbull談では「八面体」は出ず。**要検証**。
- うねる面には直径2〜3ft、長さ6〜8ftのドラムを使用(Trumbull談)。
- 追加: **Jupiter machine**: 絵画(ガラススライド)を投影し、カードの縁でスキャン=スリットスキャンの変種。1露光4〜5時間。[Trumbull談で確認]
- 月面ミニチュア: 約20x20ftの粘土モデル。木星の衛星は35mmガラススライドに絵具で描画。[Trumbull談]

## 6. 再現アプリへの示唆(暫定)
- デジタル再現は「原画テクスチャ + スリット + カメラ軌道を多サンプルで積分」する GPU シェーダ/オフラインレンダラで可能。1コマ4分の物理露光は数百サブステップの加算合成に置き換わる。
- パラメータ候補: スリット幅/高さ、カメラ移動量、原画スクロール量、サンプル数、二重露光(左右/上下ミラー)、色グレーディング。
