# Star Gate デジタル再現アプリ 設計案 (v0.2)

根拠: [research-stargate.md](research-stargate.md)。調査で不確定な値は**すべてパラメータ化**し、プリセットと許容範囲を持たせる。

## 1. 目標と非目標
> **スコープ(ユーザ判断 2026-10-15): このアプリは Star Gate の「スリットスキャン・トンネル」のみを対象とする。** Mindbender・風景素材・Jupiter/爆発は対象外(下記参照)。

- 目標: 1968年の物理装置(スリット板 + 背面照明原画 + 前進カメラ + 多重露光)を**物理モデルとして**デジタルに再現し、似た映像を生成・書き出せる。見た目の模倣ではなく、装置パラメータを動かして結果が変わることを重視。
- 非目標: AI生成、実写合成、リアルタイム音声同期。Mindbender、風景素材取り込み、Jupiter machine / 宇宙爆発(ユーザ判断で対象外)。

## 2. 技術スタック(推奨)
- **TypeScript + WebGL2(Vite)**。ブラウザでリアルタイムプレビュー、設定共有が容易。
- 書き出し: オフライン高品質レンダ → PNG連番 → ffmpeg(ProRes/H.264)。Macローカルで完結(ffmpeg CLIまたはWASM)。
- 代替案: Rust/wgpu ネイティブ。高速だが初期コストが大きいため、ボトルネックが出てから検討。

## 3. 物理モデル(コア)
座標: スリット面を z=0、カメラは光軸 z 上を c(t) で移動、原画パネルはスリットの背後 z=-d。単位は ft(調査の寸法に合わせる)。

- スリット: 縦長の矩形(高さ H_s, 幅 w_s, 横オフセット x_s)。カメラ視野の中でスリットを通る光線のみがフィルムに届く。
- 1コマ = 露光中の N 個のサブステップ k=0..N-1 を**加算合成**(実機の長時間露光の積分)。
  - サブステップ k: カメラ位置 z_k(トラック始点→終点を補間、イージング可)、原画オフセット a_k(スライド量)。
  - 画素 (u,v) の光線がスリットを通るか判定 → 通れば、その光線が原画面と交わる点でテクスチャをサンプリングし加算。
  - カメラが前進するとスリット像の画面位置が中心から外へ動く → 放射状のストリーク(トンネル感)。
- 2回露光: スリットの横オフセットを ±x_s にして2パス(左右の「壁」)。フィルム上で加算。
- コマ間: 原画の開始位置 a_0 を毎コマ少しずつ進める(アニメーション)。また回廊加速(調査:「小モーターで徐々に加速」)= a_0 と z進行の増分を時間関数で可変。
- 被写界深度: 実機は F/1.8、深度 15ft〜1.5in。初期は省略可。オプションで絞りぼかし(サブステップ内の微小ジッタ)。

実装: フラグメントシェーダで1パス=1サブステップ(スリット領域のみ描画)を float 蓄積バッファ(RGBA16F/32F)に加算ブレンド。N=64〜512(プレビューは小、書き出しは大)。

プリセット: `Two-Wall-Classic`(アプリ既定: 左右2面・縦の空白・ノイズ原画。docs/samples/m3-frame-1.png とピクセル一致。以降のコマは左壁のスライド方向を外向きに直したため左半分のみ異なる)/`Two-Wall-Top-Bottom`(同じ効果を90°回転)/`Trumbull-Strict`(調査値そのまま)/`Variant-A`(露光1分・スリット4ft)/`Vivid-Bands (optional)`(任意: 帯状の高彩度原画・鮮やかな色処理・`sharpness`)/`Free`。

## 5. 素材(原画)ジェネレータ
実機は科学写真・建築図面・回路基板・電子顕微鏡写真・結晶・花/サンゴ・絵具/化学薬品。モジュール化して選択・ブレンド:
1. 手続き生成: ドメインワープノイズ、Reaction–Diffusion、Voronoi/結晶、回路基板風パターン、フラクタル
2. ユーザ画像の読み込み(自分の写真・スキャン)
3. 流体風(インク滴下): 後段で2Dシミュレーション(任意)
パレットは色分解処理(§6)で最終的に支配されるため、原画はグレー/高コントラストでも可。

## 6. 色処理パイプライン(トンネル映像のカラーグレーディング)
調査: 3色分解(YCM)+高/低コントラスト版+ホイールでランダム設定(Loftus)、確度中。
- 入力(スリットスキャンのレンダ結果)を R/G/B チャンネル(3ストリップ)に分解。
- 各ストリップに高コントラスト/低コントラストカーブを適用、フィルタ色(CMY)でタイント。
- 合成: ストリップ毎に「ランダムホイール」= 時間でスムーズに(またはステップで)変化するパラメータ(フィルタ色・強度・反転有無)でミックス。
- 「12ストリップ」の内訳が不明のため、**ストリップ数・組合せ式はプラグイン構成**にし、後から差し替え可能にする。
- (風景素材の取り込みはユーザ判断で対象外。実装済みだった試作は削除。)

## 9. アプリ構成
```
src/
  core/        # 物理モデル・蓄積レンダラ(WebGL2)
  art/         # 原画ジェネレータ
  color/       # 色分解/ホイール
  ui/          # パラメータパネル、プレビュー、プリセット
  export/      # オフラインレンダ、PNG連番、ffmpeg連携
docs/ presets/
```
- UI: プレビュー + パラメータパネル(§4の範囲スライダー)+ 簡易タイムライン。
- 決定性: 乱数シード固定で再現可能。プロジェクトJSON(パラメータ+シード+素材参照)。

## 10. マイルストーン
1. **M1 コア(最優先、完了)**: 平面原画 + 1スリット + カメラ前進の蓄積レンダ、静止画で放射ストリークを確認。パラメータパネル。
2. **M2**: 2回露光、コマ間アニメ、プレビュー再生、手続き原画3種。
3. **M3**: 色処理パイプライン、PNG連番/ffmpeg書き出し(2.2:1, 24fps, 解像度可変)。

## 11. 検証方針
- 目視比較: 本編スクリーンショット(私的参照のみ・リポジトリ非同梱)との「トンネル幾何・色帯の流れ」比較。
- 数値テスト: 既知カメラ位置でのスリット像画面位置の解析解とシェーダ出力の一致(単体テスト)。
- パラメータ感度: 不確定パラメータを範囲内で振り、見た目が破綻しない範囲を記録 → 調査未確定点の絞り込みに逆利用。

## 12. リスク
- 蓄積精度(加算の量子化): float16/32 バッファで対処。
- 書き出し性能: 4K x N=512 x 数千コマ → GPU時間。サブステップ分割・タイル描画・進捗/再開機能。
- 著作権: 映画素材は同梱しない。
